## Windows 桌宠第一版

### 当前开发版 · 持续对话框与按键语音

对话框位于快捷卡片最上方，保持输入形态；主卡片左、右边界一致，环绕快捷控制按钮放在右侧独立列。模式选择支持“智能对话 · Codex”、自定义 API、本地指令和浏览器搜索，快捷问答与完整问答仍独立上下文。“＋”打开问答与服务设置。

按麦克风开始录音，再按结束；识别文字留在输入框供校对，确认发送后才调用同一个本地命令执行器或所选聊天后端。取消、Esc、隐藏或休眠会停止设备；录音最多 60 秒。默认 STT/TTS 使用 Windows 已安装的本地语音组件，无需密钥；聊天默认 Codex 并使用其账户额度。系统语言包及识别准确度因电脑而异，缺少组件时保留文字输入。回复可以手动朗读；设置中可开启自动播报和配置录音快捷键。新录音中断旧播报；朗读上限 600 字，跳过代码。

语音设置与文本模型分开，可选 OpenAI 兼容 STT/TTS API，分别填写地址、模型、音色与加密密钥。选择 API 后录音或播报文本会发送给该服务，费用由该服务决定。下方 0.7/0.8 小节保留版本历史，不代表当前快捷入口行为。真实麦克风验收状态见 [M3 验证记录](docs/m3-voice-verification.md)。

### 0.8 · 问答稳定性与发布流程

桌宠快捷问答和完整问答分别使用独立 Codex 会话：快捷问答不读取完整窗口选择的参考项目。快捷回答按请求编号在本次运行中保留最多 40 条，查看、复制和重显绑定同一条回复，重启桌宠后清除。桌宠快捷问答按请求归属跟踪：生成期间发送按钮禁用，可停止当前桌宠请求；关闭问答窗口只取消由该窗口发起的请求。快捷输入提供查看完整回答、复制和重新显示上一条气泡。长回复显示摘要，完整窗口支持基础 Markdown 与代码块。设置中可调整快捷概览顺序及最大显示数；问答窗口重新打开时重新计算避让。系统卡片收起期间保留窗口空间。

运行 `npm run release` 将先在独立目录构建并运行完整冒烟，再将现有发布目录保留为备份并迁移用户 data 目录。如果桌宠仍运行导致文件被占用，请退出后重试。备份路径和新版本输出会显示在终端。

### 0.7 · Cult UI 胶囊输入与 ChatGPT 网页模式

下方新增 Cult UI 胶囊工具条：聊天图标展开普通问答，指南针图标展开搜索，窗口图标打开完整问答窗口。Esc收起输入。普通问答默认复制问题并打开ChatGPT官网，由你粘贴发送，不调用Codex模型；ChatGPT自身限制仍适用。搜索直接使用配置的引擎。需要读取项目时，在完整窗口显式选择“Codex · 项目问答（使用额度）”。

设置、状态卡、气泡、音乐控制与对话窗口使用统一浅色界面。字体/选择显示内容/开机启动/媒体与Codex权限等原设置继续保留。设置页提供显示、音乐、系统、通知分类跳转。

实际使用Cult UI MIT CollabToolbar源码，在构建时用React生成静态组件和本地CSS；桌宠运行时不引入React或着色器循环，SVG角色引擎保留。构建依赖通过`npm install`安装，`npm start`和`npm run package`会先构建UI。第三方许可在`third-party/`。用户指定的setup skill已安装在`.agents/skills/setup/`。

使用和验证见 [0.7记录](docs/cult-ui-verification.md)。

### 0.6 · 问一问、浏览器搜索与动作预览

状态信息只显示已勾选且有有效数据的内容：网易云未运行/没有媒体会话、VPN未启用、Codex额度不可用或硬件计数器不可用时自动收起，不再显示占位行。有效的0%/0KB/s保留；详细错误仍可在状态面板查看。

点击宠物下方“问一问”或托盘同名菜单打开输入窗口。选择“Codex · 只读问答”后可连续提问、选择参考项目、停止和新建会话；切换参考项目会开启新会话。使用当前Codex登录与默认模型，不自动发送问题；发送会消耗正常Codex额度。固定只读沙箱，不提供写入批准，问答连接中禁用插件和MCP工具并检查禁用状态。桌宠不另存消息历史，Codex可能按其自身配置保存本机会话。

切换到“浏览器搜索”只在默认浏览器打开搜索结果，不把相同内容发给Codex。在输入窗口展开“搜索设置”，可选Bing/Google/百度或带`{query}`的HTTPS模板。配置立即保存。选择项目和输入内容只在你发送后用于问答/搜索。

输入聚焦、连接、提交、接收回复、消息到达、启动/恢复和退出分别接入listening/loading/sending/receiving/notifying或surprised/spawning/powering-down；音乐播放改用dictating波形并保留音符。媒体操作失败用confused，抚摸彩蛋包含短暂angry。高负载仍只在idle出现。

“动作预览与状态检查”提供39种已有状态的限时预览和取消。progress/uploading/orbit等没有真实下载、备份或计时来源的动作仅供预览，不代表任务在执行。本版没有新增浏览器下载扩展或麦克风读取。详见 [输入与动作验证](docs/assistant-verification.md)。

### 0.5 · Codex 细分动作与空闲负载提示

高负载动画仅在宠物为空闲 idle 时显示，交互、Codex、音乐、睡觉和自主动作均优先。Codex 新一轮输入后或工具之间显示 thinking；工具执行前按可识别的搜索/文件编辑切换 searching/writing，未知工具保留 working；结束后返回 thinking。明确的工具失败先显示 confused，若最后一次工具仍失败便结束本轮，显示 sad；正常结束先 proud，再 celebrate。正常结束仅表示本轮结束，不保证整个项目或测试成功。手动中断单独提示，不冒充失败。

需在原有五种 hooks 基础上新增 PreToolUse。点击“接入/重新连接工作状态”或运行 `node scripts/install-codex-hooks.cjs` 可合并更新并备份原配置，新聊天中生效。桥接只转发动作分类、工具调用ID和失败标记，不转发工具参数、输出或文件内容。部分工具没有 hooks，或缺少明确退出状态时，无法精确分类或判断失败。详见 [动作验证](docs/activity-animation-verification.md)。

### 0.4.1 · 下方信息与音乐控制

信息固定在宠物下方，上方独立显示消息/歌词气泡，两者可同时显示。下方提供上一首、播放/暂停、下一首按钮，直接请求控制网易云媒体会话；沿用信息栏的鼠标移入、永久显示、永久隐藏设置。鼠标从宠物移向按钮期间保持展开，只有按钮区域接收点击，其他透明区域仍可穿透。网易云没有可用媒体会话时不显示按钮；播放器拒绝控制时显示原因。切换上一首/下一首会清除手动歌词校准。

### 0.4 · 网易云音乐联动与本地歌词

播放网易云音乐时，空闲桌宠会哼歌并浮出音符，暂停后恢复；Codex 待处理与高负载动作优先。双击桌宠，在音乐区查看歌名、歌手和播放状态，可分别关闭音乐联动、歌曲提示、歌词气泡；信息显示区可单独勾选音乐行。

本机网易云 3.1.41 不提供系统媒体时间轴，因此显示“未提供时间轴”，不显示虚构的播放进度。导入当前歌曲的本地 LRC 后，输入当前播放时间（秒或分:秒）并点击校准，即可手动同步歌词；暂停会跟随，切歌会清除校准。在网易云里跳转播放位置后需重新校准。支持系统时间轴的版本会优先使用真实进度。歌词仅绑定导入时的歌名和歌手，保存在同一用户数据目录的 `lyrics.json`。

详见 [音乐验证与浏览器下载接入方案](docs/netease-music-verification.md)。浏览器扩展尚未实现或安装。

### 0.3 · 显示设置与开机启动

双击桌宠，在面板顶部“桌宠信息显示”设置：12/14/16字号（默认14），Codex额度、网速、VPN/代理、CPU、内存、GPU与音乐独立开关，以及“鼠标移到宠物时显示 / 永久显示 / 永久隐藏”（默认鼠标移入显示）。设置立即保存，重启保留；全不选则不显示信息文字。

开机启动开关在面板和托盘菜单中，使用当前EXE的路径注册Windows当前用户登录启动。初始不自动注册；启用后请保留程序路径，移动程序后重新开关一次。面板同时反映Windows是否禁用了该启动项。没有实际重启系统验证登录启动，当前未代用户开启。

### 0.2 · Codex 与系统状态

新增 Codex 额度（每 60 秒刷新）、工作/待审批/完成气泡、实时上传下载、系统代理与 VPN/TUN 状态、CPU/物理内存/GPU 最忙引擎使用率及专用显存已用量。双击桌宠或右键选择“Codex 与网络状态”打开详情面板。

持续高负载 8 秒触发忙碌动画，极高负载触发紧张动画；回落后保持 15 秒再恢复，避免尖峰频繁切换。CPU 高阈值为85%，内存/GPU为90%，极高阈值为97%。不支持或失效的计数器显示不可用。

额度通过已登录的官方 Codex CLI App Server 查询，不发起模型生成；桌宠不直接读取或保存登录令牌。接入任务事件可在面板点击“接入 Codex 工作状态”，或运行 `node scripts/install-codex-hooks.cjs`。它会合并 `~/.codex/hooks.json`，保留原 hooks 并在修改前备份；新聊天或重新打开 Codex 后生效。退出桌宠时 hooks 不会阻塞 Codex，不会自动批准请求。移除接入：`node scripts/uninstall-codex-hooks.cjs`，仅移除本应用标记的处理器。

Windows 其他应用通知需在面板点击“启用 Windows 通知”。首次可能出现本机说明窗口，请自行请求系统权限；已允许时会直接开始读取。仅转发新到达的系统通知，未发出系统通知的应用内消息无法读取。默认不启用、每次启动需手动开启，不上传、不保存通知历史。权限/系统不支持时显示错误；某些系统可能需要有应用标识的安装包。当前尚未完成真实第三方通知端到端验收。

系统指标桥接使用 .NET 10 Windows Desktop Runtime；本机已安装。源码构建桥接：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-bridge.ps1`，再执行 `npm run package`。网速只统计物理网卡，排除 TUN、Hyper-V、过滤驱动，VPN/TUN 状态不代表外网可达，不提供 VPN 开关。

实现与验证见 [第二版验证记录](docs/codex-companion-verification.md)。

本地自用的桌宠入口与原演示页独立，原角色引擎保持不变。

- 已打包时：双击 `dist/BlobPet-win32-x64/BlobPet.exe`，或根目录 `Start-Pet.cmd`。
- 源码运行：安装 Node.js 后执行 `npm install`、`npm start`。本机也可使用 `.runtime/electron` 下的缓存运行包。
- 单测：`npm test`；真实 Electron 冒烟：`npm run smoke`；打包：`npm run package`。

点击角色可以抚摸；按住角色拖动移动；右键角色或系统托盘图标打开设置。托盘双击显示桌宠。菜单包含暂停、隐藏、叫醒、漫游、置顶、气泡、大小、颜色、身形、位置恢复和退出。

无人互动约 60 秒开始犯困、90 秒睡眠，点击可叫醒。漫游仅在清醒空闲时发生，范围约为放置位置左右各 100 DIP；指针靠近时停步，便于点击。开机启动可在设置中开关，没有全局键盘监听。

打包版设置保存在 EXE 同目录 `data/settings.json`，移动应用时请保留整个文件夹。开发版保存在 `.runtime/user-data/settings.json`，冒烟使用独立 `artifacts/smoke-data`。隐藏或暂停会停止角色动画；关闭窗口收至托盘，使用菜单“退出桌宠”完全结束。

打包输出是包含 Electron 运行时的应用文件夹，`BlobPet.exe` 需要同目录 DLL 和 resources，不能单独搬走。程序使用自定义图标，尚未数字签名。

### 下载与安装联动

进度动作的圆环直接显示任务百分比。可识别的暂停状态会释放下载动作，音乐可以继续驱动桌宠；百度网盘暂停识别依赖其公开的“全部开始／继续”或暂停文本。音乐播放使用原版循环 dictating 动画，各圆点按原有节奏错开律动，当前不启用音量峰值驱动。系统信息卡片避让采用约 280 毫秒的平滑移动。设置中可分别隐藏音乐、下载、工具栏和系统卡片；拖动边界以宠物本体为准。

在设置的「下载与安装联动」中分别启用 Edge、Chrome、迅雷、百度网盘和安装窗口检测；默认关闭。百度网盘需打开传输列表，当前版本读取公开的下载总进度，无法确认结果时显示未知。迅雷及安装程序仅在窗口公开可识别的进度时显示百分比；找不到进度不代表任务完成。

Edge／Chrome 需要点击「准备浏览器联动」，然后在浏览器扩展管理页打开开发者模式，选择「加载已解压的扩展程序」并选择自动打开的 `browser/extension` 文件夹。扩展只读取浏览器下载状态、字节数和文件名，通过本机原生消息传给桌宠；不发送下载网址。扩展弹出页面与桌宠设置均提供开关。桥接登记在当前 Windows 用户的浏览器 NativeMessagingHosts 项下，不会覆盖同名的其他程序。

下载完成和中断动作只由已观察到的明确结果触发；无法确认结果的下载或安装不会伪造完成状态。浏览器扩展需由用户自行加载，关闭对应开关即可停止桌宠处理该来源。

### 专注计时与系统趋势

在设置页的“专注计时与免打扰”中选择 1–180 分钟（默认 25 分钟）及 progress／orbit 动作，支持暂停、继续和结束。暂停期间仍保留免打扰；关闭应用后计时不恢复。专注时桌宠暂缓普通提示和歌词，保留已有紧急提醒；结束后合并普通提示，避免重放。该功能不切换 Windows 系统免打扰。

展开 CPU、内存或 GPU 指标可看到最近 60 秒趋势，纵轴固定为 0–100%，缺失采样会断线；历史仅保留在内存中。设置页可调整高负载阈值及持续秒数；极高负载保持 97% 持续 8 秒规则。负载动作仍只在空闲时显示。

专注计时和持续负载均提供桌宠快捷卡片：专注可直接开始、暂停、继续和结束，展开调整时长与动作；负载卡片展开保存阈值。两项可在“快捷卡片显示”中分别隐藏。专注设置、负载设置和系统详情互斥展开；系统详情展开后隐藏重复的概览指标。趋势图使用卡片全宽，启动后逐步积累最近一分钟数据。

### 自定义 API 模型

入口：设置与状态 → API 模型聊天 → 配置 API 服务与模型，或“问一问”→ API 服务与模型配置。支持 OpenAI 兼容 Chat Completions（流式 SSE 及普通 JSON），可保存最多 20 套配置，每套指定服务地址、密钥和模型 ID。Base URL 示例 `https://example.com/v1`；本机服务允许 `http://localhost:端口/v1`。也可填写完整 `/chat/completions` 地址。原生 Anthropic、Gemini、Azure 专用协议与仅支持 Responses 的模型暂未适配。

保存时不发请求；选择“API · 自定义模型”后发送才访问所选服务，可设为桌宠快捷聊天的默认后端。服务费用和额度由 API 提供者决定，ChatGPT 网页订阅不等于 API 额度。切换后端或 API 配置会开启新会话；两个问答入口仍独立。API 模式仅发送聊天文本与本入口最近成功对话，不自动读取参考项目、系统指标或本机文件。

密钥由 Electron 主进程使用系统 safeStorage 加密，写入当前数据目录的 `api-profiles.json`。界面仅返回密钥是否存在，密钥栏留空保留旧密钥，勾选清除则删除密钥。加密文件与当前系统用户绑定，不保证可迁移至其他电脑或用户。不要将 data 目录放进开源仓库。停用配置中的“快捷聊天默认使用 API”可恢复 Codex 快捷聊天；完整窗口仍可独立选择后端。

### 本地指令、提醒与待办

在桌宠快捷输入框输入明确指令，或在“问一问”选择“本地指令”。支持“开始专注25分钟”“暂停专注”“继续专注”“结束专注”“暂停音乐”“播放音乐”“下一首”“上一首”“隐藏系统卡片”“显示系统卡片”等。音乐、下载、专注、负载卡片和工具栏均可显隐；本地指令不调用模型，模糊表达不会猜测执行。在 API／Codex 聊天模式下，未匹配的内容继续交给当前模型；本地指令模式则只提示未识别。浏览器搜索模式保持搜索行为。

提醒示例：“10分钟后提醒我喝水”“1小时后提醒我检查下载”“明天下午3点提醒我交材料”“添加待办：整理桌面”。当前时间解析使用阿拉伯数字和本机时区；已过去或无效的明确时间会提示修改。设置页提供内容、提醒时间、每天／每周重复及重要提醒；不填时间为普通待办。列表可完成、5分钟后提醒或删除；桌宠有未完成项时显示提醒入口。

数据保存在当前 data 目录的 reminders.json。应用运行时每秒检测，休眠后按实际时间检测；应用退出时不发通知、不唤醒电脑，重启后保留并检测已过期项目。同一到期项在本次运行中只入队一次，重启后未确认的到期项可再次提示。普通提醒遵循桌宠专注免打扰，重要提醒仍可提示；被合并或队列挤出的普通提示仍可在待办列表查看。完成重复提醒后排到下一次，不重放错过的每一期。损坏文件会保留并提示错误，不自动覆盖。

### 场景与提醒卡片

原专注卡片现可手动选择专注、休息、喝水、护眼、提醒和待办。专注使用计时器与免打扰；其他定时场景创建本机持久化提醒；待办不要求时长。展开“场景与提醒设置”可修改名称、执行方式、分钟数、提醒内容、重要性、重复方式及专注动作。点击保存后开始生效，也可另存为最多 12 个自定义场景并在下拉框复用或删除。

运行中的提醒会在卡片显示剩余时间，可取消；完成和稍后提醒在提醒待办列表操作。删除自定义场景不删除已创建的提醒。专注时长 1–180 分钟，提醒延时 1–10080 分钟。本版情境由用户手动选择，不会自动检测前台应用、游戏或健康状态。


### 网络趋势、提醒确认与基础养成

展开系统卡片可查看最近 60 秒网络下载（蓝）和上传（绿）曲线，单位为 KB/s 或 MB/s，两条线共用动态速度刻度；缺失采样留空，趋势仅保存在内存。到期提醒快捷行提供“确定”，每次确认最早到期的一条，不影响待办或未到期提醒；重复提醒确认后排到下一次。

设置页顶部“我的桌宠”可设置名字、活跃程度和可选作息，并查看精力／心情／好感。抚摸每 5 秒最多计入一次收益；睡眠恢复精力，心情缓慢回归平静，好感不因离线下降。数据随本机设置保存（运行中每分钟、正常退出时写入），离线变化最多一天。默认不启用作息；安静活跃度禁止自主漫游，活泼提高漫游速度。养成只改变空闲动作，任务、音乐及手动互动优先；不会改变电脑睡眠或其他应用设置。喂食、追球尚未实现。
