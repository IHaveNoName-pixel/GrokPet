# M2 Windows 常用操作

设置页顶部“Windows 快捷操作”可选择 EXE 或文件夹并命名。只保存本地白名单 ID；文本不能直接传路径、参数、shell 或 PowerShell。重名返回候选 ID，通过“打开ID 编号”再次选择。设置列表也提供打开按钮；移除配置不会删除文件。已提交的应用启动不会提供关闭应用操作。

支持命令：打开 名称、打开ID 编号、查询音量、音量设为30、调高音量5、调低音量5、撤销音量、查询系统状态，以及原有音乐、提醒待办、专注命令。清晰命令在模型调用之前本地分流；未配置目标报错，普通聊天继续所选后端。多个目标不自动选择。打开请求两秒内防重复，音量和媒体操作串行拒绝重复提交。

音量按 Windows 默认播放设备主音量处理，保持静音状态；调整后支持撤销到上次音量，外部改变音量后拒绝覆盖式撤销。接口依据 Microsoft Core Audio：https://learn.microsoft.com/en-us/windows/win32/api/endpointvolume/nf-endpointvolume-iaudioendpointvolume-setmastervolumelevelscalar

验收：108 项单元测试通过，包含目标保存恢复、重名候选、未知 ID、失效路径、重复打开、音量查询／设置／撤销、外部变更保护及显式命令识别。原生桥接构建零警告零错误，真实主音量查询和保持当前音量的写入通过。Electron M2 专项及本地命令专项通过，确认本地命令不调用模型。

应用启动与文件夹打开通过受控依赖测试；尚未替用户配置或启动私人应用。发布后由用户选择实际目标。真实鼠标、多屏和系统 DPI 的全面验收仍未完成。
