# 网络趋势、到期确认与最小养成验收（2026-10-29）

- 网络历史同时保留下载和上传的真实字节速率，不按负载百分比截断；保留最近 60 秒，最多 120 点。不可用数据留空、超过 6 秒断线；双线共用动态刻度，零速保留。
- 提醒快捷卡片保留列表入口，另有“确定”。按到期时间确认一条，操作绑定具体 ID；服务端只接受当前仍为 due 的提醒，重复或迟到确认不能把下一期提前完成。待办和未到期项保留。
- 个性设置支持名字（1–24 字）、安静／标准／活泼、可选本地作息。默认作息关闭；安静禁用漫游，活泼提高速度，原有关闭漫游设置始终有效。
- 精力、心情、好感随设置保存；睡眠恢复精力，抚摸每 5 秒最多计入一次收益。心情缓慢回归 50，好感不随离线衰减。离线最多计算一天；不积累负值或欠账。数据每分钟及正常退出保存；强制结束可能丢失最近一分钟变化。
- 养成只调整 idle 动作，不覆盖音乐、问答、下载、专注和手动互动。没有实现投喂或追球。

验证结果：98 项单元测试通过。专项 Electron 验收覆盖原生可点击区域内的 Chromium 鼠标事件、确认后隐藏、重复提醒顺延、待办保留、迟到请求拒绝、双线宽度及路径、个性设置保存重读和非法作息拒绝。截图检查：`artifacts/network-trends-preview.png`、`artifacts/personality-preview.png`。

100%／125%／150% Electron 模拟缩放下的布局验收通过。截图验收进程首次遇到 GPU 截图 UnknownVizError，禁用 GPU 的独立验收进程通过；未修改正式运行版本的 GPU 设置。此处的鼠标事件验收不等于 Windows SendInput 实测；真实多屏、系统 DPI 切换和长期养成平衡仍待验收。
