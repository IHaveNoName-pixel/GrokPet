# GrokPet 使用说明

适用日期：2026-10-30，Windows 当前运行版。界面名称可能沿用“软团”“BlobPet”；均指本项目桌宠。开发与构建见 [开发文档](DEVELOPMENT.md)。

## 1. 启动与基本操作

正式程序位于项目的 `dist/BlobPet-win32-x64/`，运行 `BlobPet.exe`，也可使用该目录的 `启动桌宠.cmd`。请保留整个文件夹；EXE 不能脱离同目录 DLL、resources 和 data 单独移动。

| 操作 | 效果 |
| --- | --- |
| 单击桌宠 | 互动、叫醒或短暂回应 |
| 按住桌宠拖动 | 改变位置；边界以宠物本体计算 |
| 双击桌宠 | 打开设置与状态 |
| 右键桌宠/托盘 | 外观、显示、暂停、隐藏、恢复位置等菜单 |
| 托盘双击 | 显示桌宠 |
| 菜单“退出桌宠” | 完全退出；关闭设置窗口不等于退出程序 |

托盘菜单可调整大小、颜色、身形、置顶、漫游和气泡。找不到桌宠时先从托盘显示，再使用位置恢复项。暂停/隐藏不等于删除提醒或配置。

## 2. 快捷卡片、轮播与环绕面板

鼠标移到宠物附近可显示快捷区。设置的“显示方式”支持鼠标移入显示、永久显示、永久隐藏。

- 列表：卡片独立排列，高度受限；用鼠标滚轮查看超出部分。滚动条已隐藏，上下渐隐提示还有内容。
- 轮播：对话框也是其中一张卡片，点击底部圆点或左右箭头切换；卡片非输入区域支持横向拖动。
- 右侧按钮：快捷控制、剪切板、列表/轮播切换。它们随快捷区显隐，鼠标移到按钮上时保持显示。
- 系统概览：短指标优先同排，放不下换行；点击展开同窗口环绕详情。
- 快捷控制：围绕宠物展开设备和应用卡片，下方快捷区先收起；关闭后恢复原位置。

设置中“快捷卡片显示”控制音乐、下载/安装、工具栏、系统、专注、负载、工作等可配置项；隐藏卡片通常只改变显示，不停止对应后台服务。服务启停使用各模块自己的开关。

“选择显示内容”控制系统详情项目；“收起时快捷显示”、顺序和最多显示数控制概览。无有效来源的项目会隐藏，有效的 0% 或 0 KB/s 仍可能显示。

## 3. 智能对话与浏览器搜索

在对话卡片输入文字并发送，回复以宠物气泡显示。生成期间可点停止；长回答可打开“完整回答”，也可复制、重显或朗读同一条回复。对话记录可展开并滚动查看。

| 模式 | 行为 |
| --- | --- |
| 智能对话 · Codex | 使用本机已登录 Codex 的文本服务；正常使用其额度 |
| API · 自定义模型 | 请求已配置的兼容聊天服务，费用/限制由该服务决定 |
| 本地指令 | 只执行支持的明确命令，不调用模型；未识别会提示 |
| 浏览器搜索 | 用默认浏览器打开搜索结果，不直接生成聊天回答 |

明确的本地命令也可在聊天模式中先本地处理，浏览器搜索模式仍保持搜索行为。未配置的应用不能通过聊天临时指定路径执行。

桌宠快捷问答与“问一问”完整窗口的上下文独立；在完整窗口选择参考项目不会自动带到快捷聊天。快捷历史仅保留本次运行，重启会清空；它不是长期记忆。Codex 或 API 提供方自身的历史处理另受其配置约束。

### 配置 API 模型

1. 对话框“＋”进入服务设置，或从设置页进入 API 服务与模型配置。
2. 填配置名称、Base URL、模型 ID 和服务密钥，保存并选择该配置。
3. 如需用于快捷对话，启用快捷聊天默认使用 API；完整窗口仍可独立选择。

示例地址为 `https://你的服务域名/v1`；本机兼容服务可用 `http://localhost:端口/v1`。当前适配 Chat Completions，支持流式 SSE 或普通 JSON；不保证原生 Anthropic/Gemini/Azure 专用协议或仅支持 Responses 的模型可直接使用。

保存配置不会立即调用模型。已有密钥留空表示保留，清除需使用界面的清除选项。密钥加密存储，但不要分享 data 文件夹。ChatGPT 网页订阅与 API 计费并不相同，本项目没有免费无限聊天通道。

## 4. 本地命令与应用快捷方式

先在设置的 Windows 快捷操作中选择应用 EXE 或文件夹并命名。程序保存白名单 ID；移除登记不会删除原文件。输入“打开 名称”会查找已登记项，重名时先展示候选，再用“打开ID 编号”选择。

| 目的 | 可直接输入的例子 |
| --- | --- |
| 打开登记目标 | `打开 记事本`（需先登记该名称） |
| 查询/调整音量 | `查询音量`、`音量设为30`、`调高音量5`、`撤销音量` |
| 音乐 | `播放音乐`、`暂停音乐`、`上一首`、`下一首` |
| 系统 | `查询系统状态` |
| 专注 | `开始专注25分钟`、`暂停专注`、`继续专注`、`结束专注` |
| 提醒 | `10分钟后提醒我喝水`、`明天下午3点提醒我交材料` |
| 待办 | `添加待办：整理资料`、`查看待办` |
| 卡片 | `隐藏音乐卡片`、`显示系统卡片` |

时间和数字建议使用阿拉伯数字，以本机时区解释。“撤销音量”只恢复适用的上一次修改；外部程序改变音量后可能拒绝撤销，防止覆盖新状态。重复提交或失效路径会提示，不会盲目重试。

## 5. 提醒、待办与专注

### 场景卡片

展开“场景与提醒设置”，选择专注、休息、喝水、护眼、提醒或待办。按需填写名称、时长、内容、重要性和重复方式，保存后开始；也可另存自定义场景。

专注为 1–180 分钟；提醒场景为 1–10080 分钟；待办可不设到期时间。情境当前由用户手动选择，不自动检测你正在游戏、开会或需要喝水。

### 到期与列表操作

到期气泡支持快速处理；提醒快捷行的“确定”用于确认到期项。待办列表支持完成、5 分钟后提醒、删除及左右滑动；重复提醒完成后排到下一次。删除自定义场景不会删除先前创建的提醒。

提醒保存在本机。程序退出期间不会主动通知或唤醒电脑；下次启动会检测保留的过期项目。普通气泡不是永久通知档案，确认状态以提醒列表为准。

### 专注与免打扰

开始后显示倒计时，可暂停、继续和结束。专注期间暂缓桌宠普通通知和歌词，重要提醒仍可提示；暂停专注仍保留免打扰，结束后合并暂缓的普通提示。

专注状态保存在 `focus.json`：运行中的计时按原截止时刻恢复，退出/休眠不会冻结现实时间；暂停的计时恢复后仍暂停。该功能不改变 Windows 系统免打扰设置。

## 6. 系统状态与设备操作

系统卡片显示 CPU、内存、GPU、Codex 剩余额度、网络和连接等有效信息。展开环绕详情可查看最近一分钟 CPU/内存/GPU 曲线和网络下载/上传曲线；刚启动时需要积累采样，缺失数据留空。

网速按可识别的物理网卡汇总，排除已识别虚拟/TUN 适配器以减少重复；VPN/TUN 或代理“开启”只是配置/适配器状态，不证明外网可达。GPU 为可用的最忙引擎等指标，不同驱动可能无法读取。

持续负载卡片可调整阈值和持续时间。短暂尖峰不会立即触发持续高负载；负载动作仅在空闲时显示，不应抢占工作、交互或音乐动作。

快捷控制提供：

| 卡片 | 可用操作与限制 |
| --- | --- |
| 主音量 | 拖动音量条、查询、适用时撤销；保留当前静音状态 |
| Wi-Fi | 查看网络和状态、请求连接已保存网络；首次密码交给 Windows 输入 |
| 蓝牙 | 查看设备列表与状态、设备支持时开关；通用配对/连接交给系统 |
| 亮度 | 支持的内置显示器可拖动；不支持时打开系统设置 |
| 电池与电源 | 查看真实电池/接电状态；选择系统支持的电源计划、屏幕和睡眠超时 |
| 我的快捷方式 | 打开已配置的应用/文件夹，按白名单执行 |

设备或策略不支持时会显示原因或打开系统设置。当前没有自动切换 VPN 的功能；蓝牙“未连接”也不表示桌宠可以直接控制所有设备协议。

## 7. 网易云音乐、下载与安装

### 网易云音乐

打开网易云并播放歌曲，启用桌宠音乐联动后可显示歌名、歌手及上一首/播放暂停/下一首。音乐使用循环 dictating 律动和音符，当前不是真实音频频谱。

部分网易云版本不公开时间轴，这时不会虚构播放进度。可导入本地 LRC，并填写当前播放时间手动校准；暂停跟随播放器，切歌清除校准。播放器内跳转后需再次校准。歌词需用户提供，不自动读取账号或联网搜歌词。

### 下载与安装

在“下载与安装联动”分别开启 Edge、Chrome、迅雷、百度网盘和安装窗口检测。下载百分比驱动动作；明确暂停后会让出动作，明确完成/中断才触发结果动作。

浏览器还需安装本项目扩展：

1. 桌宠点“准备浏览器联动”。
2. 浏览器打开 `edge://extensions` 或 `chrome://extensions`，开启开发者模式。
3. 选择“加载已解压的扩展程序”，使用打开的 `browser/extension` 文件夹。
4. 检查扩展及桌宠对应来源的开关，再开始认可的下载。

百度网盘需将传输列表保持可见；其他下载器、安装器需公开可读取的控件/状态。提权安装窗口、私有绘制控件或版本差异可能只能显示“进度未知”。窗口消失、进程存在或网络流量不能单独证明任务完成；无需为验证重新安装软件。

## 8. 剪切板

点击侧边剪切板按钮，主动开启记录后，复制文字或图片会进入本次运行历史。内容直接预览，无需展开下拉。

- 点击内容：先复制该项，再尝试向打开剪切板前使用的窗口发送粘贴。
- 左滑：删除这条本地历史；也可点删除图标。
- 暂停记录：停止收集新内容；清空历史：清除桌宠缓存。
- 返回：先收起剪切板，再恢复快捷卡片。

最多 30 项，受单项/总大小限制。仅支持本实现接入的文字和图片，不是 Windows Win+V 的完整替代，不记录所有文件和自定义格式；退出即清空历史，不上传。

目标窗口关闭、前台变化、系统权限限制或激活失败时，会提示手动切回输入框按 `Ctrl+V`。发送粘贴按键不保证所有应用支持该图片格式。不要分享包含敏感剪切板内容的截图。

## 9. VS Code 配对：配对文件怎么用

配对文件由 VS Code 扩展导入，不是项目配置文件，也不需要粘贴到终端或手动修改。

### 第一步：登记项目

双击桌宠 → 设置与状态 → 工作 → Git 项目 → “选择仓库登记”，选仓库根目录。VS Code 中打开的工作区目录应与登记根目录一致；只打开父目录或未登记子目录可能不匹配。

### 第二步：安装扩展

桌宠“VS Code 联动”中点“定位扩展安装包”。在 VS Code 按 `Ctrl+Shift+P`，执行“扩展：从 VSIX 安装”（`Extensions: Install from VSIX...`），选择 `GrokPet-work-bridge.vsix`；如提示重载窗口，按提示重载。

当前运行包里的位置是 `resources/app/vscode/GrokPet-work-bridge.vsix`；源码包位于 `vscode/GrokPet-work-bridge.vsix`。

### 第三步：生成并导入配对文件

1. 桌宠“工作 → VS Code 联动”点“生成配对文件”。
2. 在 VS Code 按 `Ctrl+Shift+P`。
3. 搜索并执行 **`GrokPet: 导入本机配对文件`**。
4. 在文件选择器中选择刚生成的 `vscode-pair.json`。

正式版文件位于 EXE 同目录 `data/vscode-pair.json`；源码运行位于 `.runtime/user-data/vscode-pair.json`。请使用当前运行实例生成的文件。

配对文件 **5 分钟内有效、仅能用一次**。成功导入后由服务清理；文件消失通常是正常现象。过期、已用或重启后失效，重新生成并导入即可。不要将此文件发给别人或提交到 Git。

### 第四步：检查连接

在 VS Code 打开登记过的项目。状态栏应出现“GrokPet · 已连接”；桌宠设置显示配对和在线工作区数量。工作卡片在相关项目下显示错误/警告数量、调试和连接摘要。

扩展约每 5 秒发送心跳；20 秒无更新转离线或未知。当前仅 Windows 本机工作区，不支持 SSH、WSL、Dev Containers。只发送已登记根目录的诊断数量/调试摘要，不发送源码、终端内容或诊断全文。诊断清零和调试停止不会被当作测试通过。

### 解除配对

- 当前 VS Code 窗口：命令面板执行 `GrokPet: 断开并删除此窗口配对`。
- 桌宠端撤销：设置中点“关闭并撤销授权”，旧凭据失效。

### 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 找不到导入命令 | 确认已安装 VSIX、扩展未禁用，并重载 VS Code 窗口 |
| 找不到配对文件 | 从正在运行的桌宠重新生成；成功使用后文件会被清理 |
| 文件无效/过期 | 重新生成，并在 5 分钟内导入；不要使用其他实例的旧文件 |
| 离线或项目未登记 | 保持桌宠运行；检查根目录一致且为本机 file 工作区 |
| 显示已连接但无相关项目摘要 | 切到桌宠已登记的对应项目，等待心跳；检查 VS Code 实际打开目录 |
| 撤销后仍显示旧界面 | 等待刷新；重新生成配对文件并导入，不复用旧凭据 |

## 10. Codex 工作状态、通知与语音

### Codex 工作联动

额度通过当前登录 CLI 的查询接口读取；聊天请求与额度查询不是同一操作。若需工作动作，在设置显式点击接入/重新连接工作状态，合并安装 Hooks 后按提示新开 Codex 聊天。

安装会备份并保留已有 Hooks，不自动登录、批准请求或发送模型问题。只有正常收到的事件能分类动作，部分工具缺少事件时显示有限。普通对话结束只表示本轮结束，不表示任务或测试成功。

### Windows 通知

设置中手动启用并按 Windows 提示授权。只处理支持接口的新通知，应用内部未发出的系统通知无法接入。权限拒绝、系统不支持或应用身份不足时会提示；不能承诺所有软件都能显示消息。此功能仍有真实第三方端到端待验收项。

### 语音

点击麦克风或配置的快捷键开始，按钮再按结束；识别文字先停留在输入框，校对后发送。Esc/取消可放弃，新录音会停止旧播报，退出/隐藏等状态会释放采集。默认 Windows 本地 STT/TTS，无需语音 API 密钥，但依赖系统语言和语音组件。

“＋ → 语音输入与播报 · M3”可分别配置 STT/TTS 的本地/API 后端和快捷键，自动播报默认关闭；回复后也可手动朗读。单次录音最多 60 秒，播报最多 600 字并跳过代码等内容。

选择 API 时，录音或待朗读文本会发送到该服务，独立计费。真实麦克风、噪声与口音准确率、听感及打断仍待使用者实际验证；不方便录音时直接使用文字。

## 11. 开机启动、备份与排错

开机启动在设置和托盘中可开关；初始不代用户启用。移动程序目录后重新开关一次，使路径正确。程序需要整个发布目录，未做独立 EXE 安装器和数字签名。

退出桌宠后备份完整 `data/`。更新程序时保留该目录；不要把测试目录的 data 覆盖到正式版。密钥加密绑定本机用户，跨电脑迁移后可能需要重填，配对建议重新建立。

| 问题 | 处理 |
| --- | --- |
| 卡片没显示 | 检查显示模式、对应卡片开关和来源是否有有效数据；永久隐藏不会被普通悬停打开 |
| 没有滚动条 | 当前设计隐藏滚动条；鼠标放到列表上滚动，渐隐表示还有内容 |
| CPU/GPU/媒体不可用 | 检查 .NET Desktop Runtime、驱动/设备能力、播放器公开接口和来源开关 |
| Codex 无额度或连接错误 | 检查本机 Codex 登录、CLI 可用性及网络；桌宠不要求粘贴登录令牌 |
| 下载暂停或未知不准确 | 保持传输列表可见、刷新来源；软件版本与控件可能不支持可靠识别 |
| 语音识别失败 | 检查麦克风权限、设备、系统语言组件或 API 配置；失败不会自动执行命令 |
| 程序更新提示占用 | 从托盘完全退出再更新，不在运行目录直接打包覆盖 |
| 提醒/配置文件损坏 | 先备份并记录错误，不直接删除 data；服务可能为保护原数据拒绝写入 |

反馈问题时记录：触发步骤、列表/轮播模式、显示设置、应用版本、屏幕分辨率和缩放、相关来源状态；截图前遮盖密钥、私人对话、剪切板和项目路径。
