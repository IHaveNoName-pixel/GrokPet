# 下载与安装联动实施计划

- 浏览器：Manifest V3 扩展只监听新下载和轮询活动任务，发送经过裁剪的任务 ID、文件名、字节及明确状态；native messaging 主机和本机用户管道限制来源，断开后过期清除。扩展加载及主机注册应有可见说明和独立开关。
- 迅雷/百度网盘：仅在用户开启后识别指定程序的公开窗口/任务进度；拿不到可靠任务状态则显示不可用，不推断完成。不得扫描磁盘、读取数据库、访问账号或凭证。
- 安装：单独开关；仅识别明确的安装窗口和公开进度；不能确认结束结果时显示未知。不得控制或启动安装器。
- 生命周期：纯数据模型限制来源、校验范围、拒绝不合理更新，防重与超时；下载中 progress/receiving，确认完成 excited，明确中断 sad；明确的安装进度同理，不影响 Codex 审批及用户交互优先级。
- 先写状态模型与桥接测试，再实现桥接和界面。浏览器扩展、安装检测、下载器适配分别进行独立验证；使用隔离临时文件及假消息，不访问用户真实任务。真实端到端仅在实际可支持场景验证，不捏造结果。
- 使用现有设置/进度卡片和桌宠动画；停止与清理各来源；编写安装、权限、恢复和限制说明；完整构建、单元测试、Electron 冒烟，再安全发布。
