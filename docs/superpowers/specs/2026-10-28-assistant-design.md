# 桌宠输入与动作 0.6

用户批准：只读Codex问答，可选择参考项目，同时提供浏览器搜索、自动收起无效状态和真实事件动作。用独立可收起的输入窗口，避免透明拖动窗口争抢键盘；由下方“问一问”和托盘打开。输入区支持模式、项目选择、流式回复、停止与新会话。只读sandbox与never审批策略固定，拒绝服务端权限/工具扩展请求；不自动提问，不选择任意模型覆盖用户默认。仅用户发送才调用模型。聊天会话沿用本机Codex认证，可能由Codex按自身规则保存历史；桌宠不另存消息历史。项目变化新建会话，防止上下文串用。

搜索支持Bing/Google/百度及HTTPS自定义模板，{query}由编码后的用户文本替换，只有点击发送才由系统默认浏览器打开。输入不发送给两个目的地。

HUD只渲染已勾选且数据有效的项目，0%等有效零值保留。网易云无会话/未运行/错误/联动关闭不占行；详情面板保留诊断。

真实动作：输入聚焦listening；连接loading；提交sending；流式接收receiving；工具沿用thinking/searching/writing；通知notifying/surprised；启动与恢复spawning；退出powering-down；媒体控制失败confused；连续抚摸angry彩蛋。所有39种状态提供限时预览并可取消。没有真实下载/上传/语音/备份数据不自动触发相关动作，也不把progress循环当作真实进度。高负载仍仅idle。
