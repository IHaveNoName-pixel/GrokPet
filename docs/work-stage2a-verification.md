2026-10-30。入口：设置 → 工作 → Git 项目。选择仓库根目录登记；可命名、选择当前项目、移除登记、刷新和关闭监测。登记最多 12 项，保存在当前 data/projects.json，重启恢复。移除登记不会删除仓库。不会自动登记聊天参考目录。

## 读取范围

只读取 Git 工作树状态、分支、最近提交短哈希和标题。不读文件正文、不发送模型、不执行暂存/提交/推送/重置。未跟踪目录按 Git normal 模式统计为一个条目。干净不等于测试通过，不触发成功庆祝。

后台每 15 秒串行检查，重复刷新合并；每仓库总预算 4 秒，每命令输出最多 256 KiB。execFile 使用参数数组，清除继承的 GIT_* 覆盖、禁用 fsmonitor 和可选索引锁。停止、关闭监测或移除登记会中断当前检查并丢弃过期结果。非仓库、删除目录、输出过大、Git 不可用或超时都显示不可用，不沿用上次干净结论。Windows 不支持 Git 时需自行安装后刷新。
