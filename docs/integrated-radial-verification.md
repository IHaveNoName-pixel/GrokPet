# 同窗口环绕控制与系统详情

当前版本以 pet/index.html 内的环绕层为运行入口；不再创建第二个 BrowserWindow。展开时隐藏下方卡片和消息气泡，原有角色播放 orbit；关闭恢复原位置和角色状态，并继续使用三秒悬停停留。原来的独立 radial.html 不再是运行界面的入口。主窗口根据工作区临时调整尺寸，保存设置时仍保存原来的桌宠位置。

快捷控制与系统详情共用该环绕层。系统概览使用按内容宽度的 flex 换行，图标和短文本整体优先并排；长内容才换行。点击概览进入系统环绕详情，CPU、内存、GPU、额度、网络、连接分别为卡片，保留真实百分比、进度条与最近一分钟曲线。超过八项分页显示，不静默丢弃。选择显示内容和排序配置继续生效。

设备详情：Wi-Fi 使用 Native WLAN 读取可选网络，显示真实信号／安全／连接状态。同名同安全类型网络合并，优先当前连接／已保存项。可向 Windows 提交已保存配置的连接请求；首次密码通过 Windows 网络列表处理，不读取或保存密码，不伪造连接成功。蓝牙读取 Classic／LE 设备列表，选择后查看已连接／未连接／状态未知；通用设备的连接和配对仍交由 Windows 确认，不宣称可以直接连接所有蓝牙协议。电源详情读取可用计划、当前计划和 AC／电池的屏幕关闭及睡眠超时，允许选择后调用系统 API 应用；系统策略拒绝时显示原因。

只读实测：本机读取到 Wi-Fi 网络、14 条蓝牙端点、4 个电源计划，以及 AC 屏幕15分／睡眠30分、电池屏幕10分／睡眠15分。验收未切换网络、未配对设备、未更改电源计划或睡眠设置。

验收：110 项单元测试通过。Electron 专项确认展开前后窗口数量不增加、使用同一 win、底部卡片隐藏、同一个角色为 orbit、六张卡片布局、电源下拉、Wi-Fi／蓝牙列表、关闭恢复原坐标。系统详情专项确认三项短指标同排、内容不越界、同窗口七张指标卡片、网络双线、超八项分页和关闭恢复；原有快捷卡片、计时、趋势、三秒悬停专项通过。
