# 性能优化记录 · 2026-10-30

## 测量方式

使用 `desktop/performance-smoke.cjs`，隔离数据、固定系统/趋势夹具，各场景四秒，以每秒 20 次鼠标位置更新模拟现有主进程节奏。记录 document.querySelectorAll、getBoundingClientRect、DOM 变更、RAF 帧间隔及长任务。未发送真实模型请求，不记录私人内容。

这是受控的同机比较，计数仅覆盖上述入口，不等于所有查询/布局或整机 CPU。测试过程中角色照常播放动画。没有把减少调用量解释成整体性能提升同样的百分比。

| 场景 | 全页查询：优化前 → 最终包 | 布局读取：优化前 → 最终包 | 最终包帧间隔 P95 |
| --- | --- | --- | --- |
| 快捷区隐藏 | 352 → 14 | 595 → 342 | 7.1 ms |
| 快捷卡片显示 | 374 → 20 | 816 → 382 | 7.1 ms |
| 系统环绕详情 | 1189 → 13 | 353 → 356 | 7.1 ms |

前后中位帧间隔均约 6.9 ms，P95 约 7.1 ms，四秒样本中未记录到超过 50 ms 的长任务。因此本轮证据说明重复工作减少，不能据此声称所有操作延迟或所有机器帧率均已改善。未降低角色帧率、修改动画时长或降低系统指标采样频率。

## 修改内容

- UIArc 的全局控件扫描仅处理真正新增/删除的 HTML 控件树，跳过 SVG 特效和纯文本变化；已绑定控件仍由各自 observer 更新。
- 菜单/侧栏的原生命中区域观察只响应相关节点、门户增删和 body 状态，避免角色 orbit 等 SVG 动画每帧触发全页查询；菜单移动和侧栏隐藏仍更新命中区域。
- 鼠标位置处理复用稳定的 dock 矩形；尺寸/布局更新仍重新测量。播放状态未变时不重复重设图标、标题和按钮状态，隐藏区不读取无用的媒体控件布局。
- 系统概览按指标身份复用节点；曲线复用 path，只更新变化的数据；未变化的文字不重写。新增指标按原顺序插入，避免刷新移除/重建全部行。

## 验证与限制

- 172 项 Node 测试通过，日志 `artifacts/performance-tests.log`。
- 暂存安装包完整 Electron 回归与进程重启通过，日志 `artifacts/performance-packaged-smoke.log`。
- 性能专项确认历史更新不会替换概览节点或曲线路径；最终测量 `artifacts/performance-packaged-after.json`，优化前数据 `artifacts/performance-before-gaze.json`。
- 显示测试以有界等待确认异步卡片布局完成，保留窗口边界断言；一次完整运行中的零尺寸状态未在显示专项复现。没有放宽产品边界条件。
- 控件截图使用已有 capture-smoke 辅助器，处理窗口暂时没有 compositor surface 的错误，不跳过操作断言。
- 实体鼠标、多屏/DPI、真实网络/媒体负载和长期运行体验仍需现场观察。上述输入模拟和四秒样本不能替代这些验收。

复测时使用 `--pet-smoke --pet-performance-smoke`；设置 `BLOBPET_PERF_LABEL` 指定结果名称，`BLOBPET_PERF_ASSERT=1` 启用 DOM 复用断言。同一 smoke-data 的 GUI 专项应串行运行。
