# 快捷卡片、剪切板、通知和工作联动交付

2026-10-30。现有 Electron/Windows 桥接和 SVG 角色引擎继续使用；没有修改全局 Codex Hooks 或登录。

## 使用入口

- 右侧常驻三按钮：快捷控制、剪切板、列表/轮播切换。输入框继续在上方，轮播只切换下方快捷卡片；列表可滚动，不强制挤压文字。
- 快捷提醒列表接入官方 Swipe Actions，滑动显示完成/稍后/删除，也可用菜单；到期气泡提供完成、5 分钟后和查看按钮，均走原提醒执行器。
- 剪切板按钮：先收起原卡片，再展开 Timeline，返回时反向衔接；侧栏不跟随卡片收起。需点击“开启记录”，支持文字、图片详情预览和再次复制，可暂停/删除/清空。
- 剪切板仅在本次运行内暂存，最多 30 条、合计 16 MiB；单条 4 MiB、文字 20000 字、图片最多 16777216 像素。暂停不继续读取，退出清空；不发送模型、不写长期记忆。轮询可能合并极短间隔的连续复制。
- 工作卡片显示已选 Git 项目、分支、修改/未跟踪/冲突数量、Codex 工作状态和 VS Code 摘要；点击查看进入工作设置，不更改问答参考目录。

## 通知完整性

主进程在聊天/回答保护期间不取走普通通知；渲染端确认显示。若消息因竞态未显示或确认超时，已知投递才可重排；5 分钟过期、有界队列、按 ID 去重，重要提醒不受普通暂缓限制。已完成提醒不重排。停止/失败/反馈会解除旧思考保护。沿用专注期暂缓规则。

## VS Code 首批联动

源码 vscode/extension；安装包 vscode/GrokPet-work-bridge.vsix。设置 → 工作 → 定位扩展安装包，在 VS Code 从 VSIX 安装；生成配对文件后执行“GrokPet: 导入本机配对文件”。

命名管道只在本机。配对文件 5 分钟有效，仅能用一次，Windows ACL 限当前用户；使用后删除。VS Code SecretStorage 保存凭据，桌宠只保存凭据哈希。可关闭并撤销授权。摘要只含已登记根目录身份、会话序列、诊断数量、调试状态和心跳；不发送代码、诊断描述或终端正文。20 秒没有心跳即未知；最多 20 个工作区会话。首版不接 SSH/WSL/容器，不将诊断清零或调试结束视为测试成功。

## 本轮交互修正

- 剪切板移除折叠详情，直接展示文字和图片缩略图；点击条目复制并向原窗口发送 Ctrl+V。原窗口身份由原生前台事件在主进程保留，渲染端只能提交已有历史 ID；原窗口关闭、激活失败、前台改换或权限受限时提示手动粘贴，不虚报成功。条目支持左滑删除和显式删除按钮。
- 对话框纳入卡片轮播；以卡片 ID 保留选择，按活动卡片测量高度，忽略隐藏期间的零宽测量，允许从卡片按钮处横向拖动切换（输入和滑块保留自身操作）。
- 列表恢复独立卡片，去掉外层操作框及省略菜单；限制高度，滚轮滚动，上下按实际溢出显示渐隐。快捷控制和剪切板按钮常驻侧边。
- 剪切板快速开关保留最后一次操作，先收起再展开；图片条目取消额外的高度入场动画，防止预览加载时裁切内容。

## 轮播点击与侧栏隐藏修正

- 根因：`#info-dock` 的 `pointer-events:none` 被轮播导航继承，旧测试调用 DOM `.click()` 绕过了鼠标命中检查。为卡片滚动层恢复鼠标事件，保留原生整块 dock 的交互区域。
- 右侧按钮与 HUD 使用同一组显隐条件；隐藏时不发布原生鼠标区域。鼠标移到侧栏或中间间隙会保留悬停，避免操作中自动收起。
- 快捷区域隐藏滚动条但保留滚轮、触控滚动与溢出渐隐，不影响独立设置窗口。
- 专项回归改为 Chromium 鼠标输入逐一点击轮播圆点和左右箭头，并检查悬停显示/离开隐藏、无滚动条与列表滚动边界。此验证不等同实体鼠标或多屏验收。
