# 环绕快捷面板验收

入口：宠物下方工具栏新增“⌘ 快捷控制”；设置页 Windows 快捷操作中也有“打开环绕快捷面板”。独立透明浮层中环绕排列音量、Wi-Fi、蓝牙、亮度、电源和自定义快捷方式，不增加原来的下方卡片堆叠。Esc 或中心叉号关闭。窗口自动限制在当前显示器工作区；小工作区降为两列。透明卡片间隙穿透，拖动滑条期间保持鼠标捕获。

采用 Cult UI 的浅色浮层、圆角、细边框和 Halo 风格开关／滑条视觉；结合用户提供的指南，以节点、连接线和单个中心明确空间关系，不引入全屏游戏 HUD 或故障闪烁。指南：https://seclusong.xyz/2021/04/20/2021-04-20-周二-23-40-58UI笔记/

设置页音量输入也改为滑条。应用选择增加 .lnk 快捷方式，仍只启动用户通过文件选择器加入白名单的路径；没有模型提供任意参数或命令的接口。

状态与操作：音量显示实际读数并保留静音；Wi-Fi 和蓝牙使用 Windows Radios API，直接设定 on/off，权限或设备不支持时显示错误并保留 Windows 设置入口；亮度读取 WMI，写入使用固定的 CIM 方法调用，唯一可变参数是原生层校验后的 0–100 数值，不接受脚本、路径或任意命令文本。电池显示实际电量、电源接通状态，只读并提供电源设置入口。

本机真实能力：Wi-Fi／蓝牙各一台，均开启；电池存在、100%、接通电源；亮度100%。保持当前值的 Wi-Fi on、Bluetooth on、brightness 100 写入与读回均成功，未执行关闭网络或蓝牙的实测。其他设备若接口不可用，控件显示原因并可进入系统设置。无线状态表示设备无线开关，不代表已连接具体网络或设备。

验收：109 项单元测试通过；新增窗口定位测试覆盖四角、负坐标显示器及小工作区。Electron 专项覆盖六张卡片不重叠、不越界、真实状态读取、音量／亮度 range 控件、非法无线参数拒绝、设置页 range 控件和关闭。检查 artifacts/radial-controls.png、artifacts/quick-settings-slider.png。实际第二显示器与 Windows 系统 DPI 切换仍未验收；模拟定位或 Chromium 输入不代表真实硬件多屏验收。

首次截图中设置页被浮层遮挡，capturePage 返回 UnknownVizError；验收先关闭浮层再拍设置页后通过。没有修改正式运行的 GPU 设置。
