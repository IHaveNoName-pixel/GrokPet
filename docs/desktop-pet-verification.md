# 桌宠第一版交付与验证

日期：2026-10-27。Windows x64，Electron 41.10.6。

## 启动

应用：`D:\.Net\Example folder\grok-icon-study\dist\BlobPet-win32-x64\BlobPet.exe`。

也可双击项目根目录 `Start-Pet.cmd`。应保留整个应用文件夹，不能只复制 EXE。源码入口 `desktop/main.cjs`，角色页 `pet/index.html`；原动画演示及引擎未修改。

## 已实现

- 透明无边框悬浮；角色矩形范围内可交互，外围鼠标穿透。
- 拖动移动，放下弹跳，点击抚摸和气泡反馈，桌面光标注视。
- 清醒空闲时在放置位置左右各约 100 DIP 漫游，光标靠近停步。
- 60 秒无互动犯困，90 秒睡眠，点击叫醒。
- 角色右键菜单和托盘菜单：显示/隐藏、暂停/继续、叫醒、漫游、置顶、气泡、大小、颜色、身形、恢复位置和退出。
- 设置和位置本地保存，多屏工作区钳制和屏幕移除恢复。
- 暂停/隐藏停止角色 RAF；系统休眠停止活动，恢复后苏醒。

## 实际验证结果

`node --test tests/*.test.cjs`：8 项通过，0 失败。涵盖行为优先级、休眠苏醒、漫游开关、负坐标屏幕、命中穿透范围、无效配置、保存重开和损坏 JSON 备份。

`node scripts/smoke.cjs --packaged`：最终 `BlobPet.exe` 启动与自检通过，并退出后重新创建进程验证设置恢复。

- SVG 实际初始化，页面背景透明，渲染进程无法访问 Node。
- Electron 输入事件触发抚摸，通过渲染层 → IPC → 行为状态的拖动开始/释放链路。
- 颜色、身形、尺寸、置顶切换；配置写入后重新读取。
- 暂停时 RAF 停止；活动中隐藏会暂停，显示后恢复。
- 原生窗口实际移动，关闭漫游后停止；自主睡眠状态进入渲染层。
- 将窗口置于屏幕外后收回实际工作区；本机工作区为 1920×1032 DIP。
- 全新应用进程恢复 X/Y 位置、颜色、身形、尺寸、漫游及置顶。
- 只捕获桌宠自身页面并查看预览，未把其他应用桌面内容放入验证图。

独立代码审查发现并修复外围额外 12 DIP 吞点击问题，先复现失败再修复，复审无新的重要发现。

## 验证边界

真实系统鼠标拖拽的位移与托盘/右键菜单的逐项手动操作未完成目视验收。拖动自动化覆盖事件和状态链路，漫游自动化验证了原生窗口移动，两者不等价。当前只有单屏设备验证；多屏负坐标有单测，未实际连接第二台显示器验证。

透明窗口桌面截图曾被自动审批拒绝，原因是可能包含后方无关桌面内容。后续使用 Electron capturePage 仅检查桌宠自身页面，没有继续尝试桌面截图。
