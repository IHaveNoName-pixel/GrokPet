# Git 项目登记与只读监测

沿用已批准的 work-companion-v03 阶段 2A，在当前脏工作树增量实现，不切分支或混合提交。

- [x] 登记存储：原生目录选择、realpath、仓库根目录验证、稳定项目 ID、最多 12 项；选择/移除仅修改本地登记，原子保存，损坏备份。
- [x] 只读探测：execFile 参数数组；禁用可选锁、fsmonitor、pager；每命令 4 秒/256 KiB；porcelain -z 解析改名、冲突、未跟踪；分支和最近提交；失败不可报告 clean。
- [x] 生命周期：15 秒串行轮询，可手动刷新，重复刷新合并；取消/移除后丢弃旧结果；停止杀掉子进程；独立开关，不增加动画调度器。
- [x] 设置工作页：登记、选择、移除、刷新、开关、状态和错误；不读取文件内容，不自动发给模型。
- [x] 真实临时仓库验证 clean/dirty/conflict/空仓库/删除目录/重命名，模拟超时与停止；Electron UI/IPC 验证、打包验证后更新正式版并清理暂存包。

登记只接受仓库根目录，子目录提示重新选择根目录。Git 状态不代表构建/任务验收成功；不庆祝，不自动提交/暂存/推送。最近提交只展示短哈希和标题。
