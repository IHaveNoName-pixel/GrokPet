语音输入与播报 · M3
默认使用 Windows 本地语音，不需要密钥，录音和播报文本不发送到语音服务。聊天默认使用 Codex，仍按 Codex 账户额度计量。可选 API 模式会把录音或朗读文本发给对应语音服务，费用与文本模型分开。录音最多 60 秒，识别后先校对再发送。不录音时不采集，取消即停止设备。播报为 AI 合成语音，最多 600 字，跳过代码。
语音识别 STT
本地识别优先使用已安装的中文语言包。识别准确度受系统引擎影响，请校对后发送。
语音播报 TTS
快捷键只切换录音，不自动发送。点击麦克风开始，再点结束；Escape 或“取消”放弃录音。开始新录音会中断播报。
