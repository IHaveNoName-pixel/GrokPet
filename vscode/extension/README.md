# GrokPet 本机工作联动

仅 Windows 本机命名管道。发送已登记仓库的错误/警告数量、调试状态、会话序列和心跳；不发送文件正文、诊断描述或终端输出。不运行模型命令。

1. 在桌宠“设置 → 工作”登记仓库根目录。
2. 在 VS Code 执行“扩展：从 VSIX 安装”，选择 GrokPet-work-bridge.vsix。
3. 桌宠生成配对文件，在 VS Code 执行“GrokPet: 导入本机配对文件”，选择该文件。文件 5 分钟内有效，仅可用一次。
4. 在该仓库打开工作区，桌宠工作卡片显示错误/警告、调试和连接状态。20 秒无心跳显示未知。

凭据保存在 VS Code SecretStorage；桌宠只保存凭据哈希。桌宠“关闭并撤销授权”立即使旧凭据失效。关闭 VS Code 后，桌宠不猜测调试结果。第一次版本未实现远程 SSH、WSL 和容器工作区，也不把诊断清零当作任务验收通过。
